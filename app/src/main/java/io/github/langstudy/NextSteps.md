# Next Steps and New Features for Language Study App

## Edit functionality removal
- Change the logic that is run when tapping on an entry. Enter a view mode instead of an edit mode. That view mode should have edit and delete options.
  - Update cards in each app section to have a view mode. Cards that don't have an edit icon should get one.
- No main view in app sections should have edit features. This means adding/removing tags from journals should be stopped from the main page.
  - Tags can still be tapped. The tag tapped will filter the results by that tag. Once tapped again, the filter will be removed. Only one tag can be selected through this method.
    - Tapping Search Journal should also display an option to search by tag. With that method, multiple tags can be selected.
